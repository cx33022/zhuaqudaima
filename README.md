# 机械臂物料抓取与数字圆放置

这是机械臂的 STM32 工程。当前测试流程将物料盘中的物块依次夹起，放到对应的数字圆环内。工程使用 Keil µVision 打开 `USER/Template.uvprojx`。

## 上电与电池

接线已经完成，将外留的电源线接入大电池即可供电。

**每运行 5 分钟必须停下，然后使用电池配套充电器充电，直到充电器指示灯变绿，再继续运行。**

## 当前测试流程

1. 将双臂放到机械零点附近。电机驱动器已设置上电自动回零时，双臂会回到固定零点。
2. 确认回零结束、双臂停稳后，再启动 STM32 程序。程序将当前位置作为本次关节参考，自动前往公共点并寻找数字圆。
3. 识别到数字圆后进行中心定位，PG15 闪烁表示定位完成并等待按键。
4. 按 PC9 后，机械臂从后方物料盘夹取物块放到数字圆 1，再从左一物料盘夹取物块放到数字圆 2。

注意：STM32 当前程序不会等待驱动器的自动回零完成信号。执行第 2 步前，应先确认驱动器回零完成；如果驱动器未启用上电回零，需要先把双臂摆到固定机械零点。

## 放置偏差较大时：串口点动定位

使用 USB 转串口连接 USART6：STM32 **PC6 为 TX**，连接串口模块 RX；**PC7 为 RX**，连接串口模块 TX；两者 GND 共地。串口设置为 **115200、8 数据位、无校验、1 停止位**。

在 `USER/main.c` 中将 `ARM_NEW_RING_PICKUP` 设为 `0`、`ARM_SERIAL_JOG` 设为 `1`，重新编译并烧录，即可进入串口点动模式。双臂到固定机械零点并停稳后，发送 `z` 将当前位置设为软件零点，再使用以下命令移动和记录位置：

| 命令 | 功能 |
| --- | --- |
| `1` / `2` | 5 号关节增加 / 减少一个步长 |
| `3` / `4` | 6 号关节增加 / 减少一个步长 |
| `a` / `d` | 两个关节同时增加 / 减少一个步长 |
| `+` / `-` | 步长加倍 / 减半 |
| `p` | 显示当前软件关节角 |
| `s` | 停止运动 |
| `?` | 显示完整命令 |

点动打印的角度是软件记录的目标角，不是电机实时位置回读。定位完成后，将 `ARM_SERIAL_JOG` 改回 `0`、`ARM_NEW_RING_PICKUP` 改回 `1`，重新编译并烧录测试程序。新零点下的实测位置位于 `USER/arm_new_zero_measurements.h`。
